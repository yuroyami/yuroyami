I build Kotlin Multiplatform libraries and apps. Most Kite libraries use 100%
pure Kotlin code and do not need JNI or bundled native binaries.

## 🪁 Kite libraries — 100% pure Kotlin where possible

Most core modules have no `expect`/`actual` declarations.

| Library | Purpose | Release | Docs |
| :--- | :--- | :--- | :---: |

Includes an optional Compose Multiplatform UI module. | [![kiteqr](https://img.shields.io/maven-central/v/io.github.yuroyami/kiteqr?style=flat-square&label=&color=7F52FF)](https://central.sonatype.com/artifact/io.github.yuroyami/kiteqr) | [Guide](https://yuroyami.github.io/KiteQR/) |
| **[KiteImage](https://github.com/yuroyami/KiteImage)** | Read and write PNG, JPEG, GIF, and BMP. Read TIFF, JPEG 2000, and lossless WebP. Use DEFLATE, gzip, zlib, LZ4, and Snappy. | [![kitearchive](https://img.shields.io/maven-central/v/io.github.yuroyami/kitearchive?style=flat-square&label=&color=7F52FF)](https://central.sonatype.com/artifact/io.github.yuroyami/kitearchive) | [Guide](https://yuroyami.github.io/KiteArchive/) |
